# 中文路 · 命题作文

Vue 3 + Ant Design Vue + Vite 构建的可交互原型。

## 开发与验证

```bash
npm install
npm run dev
npm test
npm run build
```

开发地址：http://127.0.0.1:5188/
构建入口：`preview/index.html`，可在现有静态 Vercel 仓库中发布。

顶部四个独立 Tab：后台、App、业务流程图、评分规则。
支持模拟业务闭环：任务创建、两种收稿入口、学生匹配、教师复核、成绩发布与学生查看；不含重写和在线订正提交。

## 范围说明

界面使用接近实际产品的字段和业务数据；不存在“演示／模拟”说明性文案。
实现为前端原型，数据仅保存于本浏览器 localStorage；当前没有真实认证、OCR、AI服务、文件上传后端或跨设备同步。图片选择仅用于本地预览，上传操作推进预设业务状态，不会把文件传出本机。

评分试算采用结构化计算；DSE 300字歧义会阻止形成可发布结果。
已有任务使用评分方案快照，创建校本方案不会改变历史任务。
角色菜单是交互呈现，不构成服务端权限控制。正式系统须按需求文档接入权限校验与真实存储。

## Cloudflare Pages 发布地址

固定入口：https://zhongwenlu.pages.dev/mingtizuowen/

源码保留于本目录。执行 `npm run build` 后，仅将 `dist/` 静态产物同步至发布仓库 `Lynnlgh0824/zhongwenlu` 的 `static-apps/mingtizuowen/`，由 Pages 构建脚本复制到子目录；不得上传讨论资料、原始截图或参考 PDF。发布时基于远端最新 main 建立临时 checkout，仅提交本子应用产物及必要部署配置，避免覆盖根站其他工作。GitHub Actions 的 Deploy Pages 完成后核对 `/version.json` 与子路径资源。

评分总览按当前方案动态展示总分公式、维度满分及封顶顺序，公式与 `src/scoring.js` 计算保持一致。

## 多任务与数据状态

共3个班级、32名学生、5个任务、56条任务学生记录（新浏览器初始数据）。后台使用当前作文任务选择器；App使用学生、作文任务选择器。中四A班陈芷晴可查看未提交任务及历史反馈，林子轩在「为不完美添色彩」为待识别，黄乐彤为AI初评中，张梓朗为需补交。中四B班提供议论文，中二A班使用校本100分方案。新增数据以幂等方式扩展，保留原有任务、教师操作和已发布成绩。

## 学校层级与多篇作文入口

后台 → 教学组织：默认展开明德小学 → 小三 → 3A，展示小明（班号15）等学生。学生作文档案同时列出独立任务的已发布、待复核、未提交作文，可进入学生端查看或教师复核。App 显示本人学校、年级、班级和班号。当前初始数据为2所学校、3个年级、4个班级、36名学生、8个任务、68条任务学生记录。稳定学生ID与班级内班号分开保存。
